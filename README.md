📊 InsightFlow - Business Intelligence Dashboard



Overview



InsightFlow is a Business Intelligence Dashboard developed using Python, Streamlit, PostgreSQL, Plotly, and Pandas. It provides an interactive interface to monitor business performance, analyze sales data, generate reports, and manage business information from a single dashboard.



This project was built to improve my skills in Python, SQL, database integration, and dashboard development while creating a practical business analytics application.





Features



\- Secure Login Authentication

\- PostgreSQL Database Integration

\- Interactive Dashboard

\- Revenue, Orders, Customers and Profit KPIs

\- Sales Trend Analysis

\- Monthly Revenue Report

\- Customer Analytics

\- Order Status Distribution

\- Latest Orders Table

\- Excel Report Export

\- Data Center Module

\- ETL Center Module

\- SQL Studio

\- Analytics

\- AI Insights

\- Reports

\- Responsive Streamlit Interface

Installation



Clone the repository



```bash

git clone https://github.com/YOUR\_USERNAME/InsightFlow-Business-Intelligence-Dashboard.git

```



Move into the project folder



```bash

cd InsightFlow-Business-Intelligence-Dashboard

```



Install dependencies



```bash

pip install -r requirements.txt

```



Run the application



```bash

streamlit run app.py

```
